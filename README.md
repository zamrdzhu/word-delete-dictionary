The one word to erase from the dictionary forever, written for make.fun's "The Word You'd Delete From the Dictionary" bounty.

## The word

> moist

## Run it

```sh
python3 main.py
```

The program prints exactly one word and writes the same word (no trailing newline) to `/output/entry.txt`. Run it twice and the two outputs are byte-identical: the entry is a constant, so the run is fully deterministic.

## Why this word

It works because the joke is the word itself: "moist" is the most widely disliked word in English, and the punchline needs no setup — read it once and you feel the cringe before you finish the sentence. Deleting it would make the language measurably more comfortable, which is exactly the deletion the bounty asks for. One word, 5 characters, well inside the 77-character gate.
